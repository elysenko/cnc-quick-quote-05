# Pipeline Task Decomposition

## Summary
CNC Quick Quote is a customer-facing quoting and ordering app for a laser/CNC cutting shop. A signed-in customer uploads a DXF drawing, the backend parses it into flattened polylines and derives cut length, bounding box and entity counts; the customer places bend lines on the part, picks a material and quantity, and the system runs a grid nesting pass (sheet count + utilisation) and a pricing pass over an admin-configured snapshot to produce an itemised quote. The customer then reviews the quote, picks a shipping method, pays through Stripe Checkout, and receives an order with an order/confirmation number plus a Resend-delivered receipt email. Admins configure materials, pricing variables, machine limits, business/branding/payment settings, shipping methods, and integration credentials, and review all orders.

**Stack reality check (binding for all agents):** the platform stack is fixed to **Angular 19 (frontend) + NestJS 11 + tRPC (`nestjs-trpc`) + Prisma 6 + PostgreSQL**, per `ARCHITECTURE.md` and `colossus.stack.json`. The spec's FastAPI/Python/`ezdxf`/Angular 22/Material design is **not** the stack — implement the spec's *features* with Node equivalents. Concretely: Prisma schema instead of SQLAlchemy models + Alembic; NestJS modules/tRPC routers instead of FastAPI routers; a Node DXF parser instead of `ezdxf`; `bcryptjs` instead of `argon2` (native addons are discouraged by the stack contract); `@nestjs/jwt` instead of PyJWT; `@nestjs/throttler` (in-memory) instead of slowapi+Redis (**no Redis is provisioned**); `minio` npm client instead of the Python client. Do not add `@angular/material` — build presentation with plain CSS in `frontend/src/styles.css` plus component styles. Respect the `.pipeline/surface.json` file budget: **400 lines soft / 500 hard per file** — split modules rather than exceed it.

## Surface contract

### Auth model
`full_auth`. Roles come from the existing Prisma `enum Role { USER MANAGER ADMIN }` (`backend/prisma/schema.prisma`) and the `colossus.stack.json` contract (`ADMIN`, `MANAGER`, `USER`). Login path is `/login`. Public surface only: `/login`, `/signup`, `GET /health`, `GET /api/health/deep`, `POST /api/webhooks/stripe`. Everything else requires a session; `/admin/**` additionally requires `ADMIN`. Platform logins are minted by Colossus and materialised by `backend/prisma/seed/seed.js` from `COLOSSUS_ACCOUNTS_JSON` — that seed stays essential-only, no demo/business rows.

### Backend surface
tRPC procedures are the default transport (`/trpc`, `glue.api_client: trpc`). **Three surfaces must be plain REST** because they cannot ride the tRPC batch link: multipart upload, the Stripe webhook (needs the raw body), and binary/stream responses.

- **tRPC routers** (alias → procedures):
  - `auth`: `register`, `login`, `refresh`, `logout`, `me`
  - `drawings`: `get`, `list`
  - `bends`: `list`, `create`, `update`, `delete`
  - `materials`: `list` (active only, authenticated)
  - `quotes`: `create`, `list`, `get`
  - `checkout`: `get`, `shippingMethods`, `createSession`, `status`
  - `orders`: `list`, `get`
  - `admin`: `materials.*`, `pricing.get/put`, `machine.get/put`, `business.get/put`, `shippingMethods.*`, `orders.list`, `settings.list`, `settings.update`
- **REST controllers**:
  - `POST /api/drawings` — multipart DXF upload (auth required)
  - `GET /api/drawings/:id/geometry` — cached flattened geometry JSON
  - `POST /api/webhooks/stripe` — raw-body signature verification (public)
  - `GET /api/orders/:id/receipt` — streamed receipt
  - `POST /api/admin/business/logo` — multipart logo upload (admin)
  - `GET /api/admin/settings` / `PATCH /api/admin/settings` — service + integration credentials (admin)
  - `GET /health` (exists), `GET /api/health/deep` — Postgres + MinIO probes

### Entities (Prisma models)
`User` (exists, extend) · `ColossusAccount` (exists, untouched) · `RefreshToken` · `Drawing` · `BendLine` · `Material` · `PricingConfig` (singleton `id=1`) · `MachineConfig` (singleton `id=1`) · `BusinessConfig` (singleton `id=1`) · `ShippingMethod` · `Quote` · `Order` · `StripeEvent` · `SystemSetting`

### Money & units
Money is stored as **integer cents** on `Quote`/`Order`/`ShippingMethod`; admin-config rates are `Decimal @db.Decimal(12,4)`. Internal geometry unit is **mm**; `cut_ft = cutLengthMm / 304.8`.

## backend_agent tasks
- [ ] Create `src/auth/` (module, service, controller-free tRPC router): `register` (409 on duplicate email, `bcryptjs` hash at 10 rounds matching the seed, role = `ADMIN` when the user table is empty else `USER`), `login` (401 on mismatch), `refresh` (rotate: revoke old row, issue new; 401 on expired/revoked/unknown), `logout` (revoke), `me`. Access token = HS256 JWT, 15 min, via `@nestjs/jwt`; refresh = opaque random, SHA-256-hashed into `RefreshToken`, 30 d, returned as an HttpOnly `SameSite=Strict` cookie.
- [ ] Create `src/auth/guards/` — `JwtAuthGuard` (401), `RolesGuard` + `@Roles('ADMIN')` decorator (403), and the tRPC middleware equivalents `protectedProcedure` / `adminProcedure` in `src/trpc/`. Wire `cookie-parser` and register guards in `app.module.ts`.

Cache resolved values in-process with explicit invalidation on settings write. Export `ServiceUnconfiguredError` mapping to HTTP **503** / tRPC `PRECONDITION_FAILED`.
- [ ] Create `src/admin/settings.controller.ts` — `GET /api/admin/settings` returns every service key (`postgresql`, `minio`) and every integration key (`MINIO_S3_MINIO_7_2_20_API_KEY`, `RESEND_API_RESEND_2_43_API_KEY`, `STRIPE_SDK_PYTHON_STRIPE_15_6_API_KEY`) with **masked** values plus a `configured` boolean; `PATCH /api/admin/settings` upserts key/value pairs into `SystemSetting` and busts the `resolveConfig` cache. - [ ] Create `src/integrations/minio-s3.ts` — typed MinIO client built from `resolveConfig('MINIO_S3_MINIO_7_2_20_API_KEY')` (plus endpoint/bucket env); throws `ServiceUnconfiguredError` when unresolved or placeholder. - [ ] Create `src/integrations/resend-api.ts` — client from `resolveConfig('RESEND_API_RESEND_2_43_API_KEY')`; throws `ServiceUnconfiguredError` when unresolved. - [ ] Create `src/integrations/stripe-sdk.ts` — client from `resolveConfig('STRIPE_SDK_PYTHON_STRIPE_15_6_API_KEY')` with fallback to the Fernet-decrypted key in `BusinessConfig` (sandbox flag selects test keys); throws `ServiceUnconfiguredError` when unresolved. - [ ] Create `src/crypto/secret-crypto.service.ts` — AES-GCM (Fernet-equivalent) `encryptSecret`/`decryptSecret` keyed off `APP_SECRET`, plus `maskSecret` for API responses. Stripe secret key and webhook secret are stored encrypted and only ever returned masked.
- [ ] Create `src/dxf/dxf.service.ts` — `parseDxf(buffer): ParsedGeometry` using a Node DXF parser (`dxf-parser` or equivalent). Supported entities: `LINE`, `ARC`, `CIRCLE`, `LWPOLYLINE` (including bulge→arc), `POLYLINE`. Flatten each to a vertex list at 0.05 mm sag tolerance, sum segment lengths into `cutLengthMm`, compute the bbox, and normalise units from `$INSUNITS` (`0` unitless → mm, `1` inches → ×25.4). Return `polylines`, `cutLengthMm`, `bboxWMm`, `bboxHMm`, `entityCount`, `skippedEntities`, `detectedUnits`. Throw `DxfParseError` on corrupt bytes, zero supported entities, or zero-area bbox.
- [ ] Create `src/drawings/` — `POST /api/drawings` multipart controller (auth required) enforcing this exact rejection order: 401 → extension not in `MachineConfig.allowedExtensions` ⇒ 422 → size > `MachineConfig.maxUploadBytes` ⇒ 422 (counted while streaming, rejected **before** storing) → `parseDxf` failure ⇒ 422 with the parser message → only then `putObject` to `drawings/{userId}/{uuid}.dxf` → persist the `Drawing` row. Response carries id, geometry, bbox, cut length, `skippedEntities`, `detectedUnits`. Plus owner-scoped `drawings.get` / `drawings.list` tRPC procedures and `GET /api/drawings/:id/geometry`.
- [ ] Create `src/bends/` tRPC router — `list(drawingId)`, `create`, `update`, `delete`. Validate `0 <= angleDeg <= 180` and `direction ∈ {up, down}` with zod (422 otherwise); owner-scoped (403 on another user's drawing, 401 unauthenticated). Never mutates the stored DXF object; any mutation marks dependent draft quotes stale.
- [ ] Create `src/materials/` — `materials.list` (authenticated, `isActive: true` only) and admin `materials.list/create/update` under `adminProcedure`. Deactivation sets `isActive = false`; hard delete is forbidden.
- [ ] Create `src/nesting/nesting.service.ts` — pure `nest({ partW, partH, qty, sheetW, sheetH, spacing, margin }): NestResult`. `usable = sheet - 2*margin`; `cols = floor((usableW + spacing) / (partW + spacing))`, rows likewise; `perSheet = cols * rows`; throw `PartTooLargeError` when `perSheet === 0`; `sheets = ceil(qty / perSheet)`; `utilization = qty * partArea / (sheets * sheetArea)`; emit top-left-origin `(x, y)` placements for sheet 1 plus per-sheet counts. - [ ] Create `src/pricing/pricing.service.ts` — pure `price({ cutLengthMmTotal, bendCountTotal, sheetCount, materialMultiplier, configSnapshot })`. `cutFt = cutLengthMmTotal / 304.8`; `subtotal = setupFee + cutFt*costPerLinearFoot + sheetCount*perSheetCost*materialMultiplier + handlingFee + bendCountTotal*costPerBend`; `total = max(minimumOrder, subtotal)`. - [ ] Create `src/quotes/` tRPC router — `create` validates quantity against `MachineConfig` min/max (422 stating the limit; rejects null/0/negative), material exists and `isActive` (422), and part-fits-sheet (`PartTooLargeError` ⇒ 422). ## Open questions
- **Backend port mismatch.** `colossus.yaml` declares `backend.port: 3001` while `backend/src/main.ts` defaults to `PORT ?? 3000` and `frontend/proxy.conf.json` targets `:3000`. Someone must pick one; backend_agent should default to `3001` to match the deploy manifest and update the proxy config, unless the deploy agent says otherwise.
- **No Redis and no MinIO in `docker-compose.yml`.** `<spec_deployments>` is `postgresql, minio`, so Redis is unavailable — rate limiting therefore uses the in-memory throttler (single-replica assumption). `docker-compose.yml` only defines Postgres + pgAdmin; a MinIO service (plus bucket-init) needs adding for local dev, and MinIO endpoint/bucket/secret-key env vars beyond the single provisioned `MINIO_S3_MINIO_7_2_20_API_KEY` are unspecified.
- **Global route prefix.** Existing NestJS routes are `/health` and `/trpc/**` with no `/api` prefix, but `glue.frontend_api_base` is `/api` and `backend_probe_path` is `/api/docs`. The plan above puts new REST controllers under `/api/**` and leaves `/health` and `/trpc` where they are — confirm this split works with the nginx front-end config before shipping.
- **Colossus roles vs. the spec.** The stack contract mandates three roles (`ADMIN`, `MANAGER`, `USER`) and mints one login per role, but the spec only describes admin and customer behaviour. `MANAGER` currently has no defined permissions — it is treated as a non-admin customer. Confirm whether `MANAGER` should get read-only admin access.
- **First-signup-becomes-admin vs. seeded admin.** Colossus always seeds an `ADMIN` account, so the spec's "first signup becomes admin" rule will effectively never fire in a deployed environment. Kept for local/dev parity; flag if the seeded admin should be the only admin path.
- **DXF parser choice.** `ezdxf` (the spec's justification for a Python backend) is unavailable. `dxf-parser` handles `LWPOLYLINE` bulges but requires hand-rolled bulge→arc flattening and bbox computation; expect small cut-length differences from the spec's fixtures. Fixture expected values must be recomputed for the Node implementation rather than copied from the spec.
- **Receipt generation format.** The spec says `GET /api/orders/:id/receipt` "streams a generated receipt" without specifying PDF vs. HTML. Defaulting to server-rendered HTML (no native PDF dependency, which the stack contract discourages) — confirm if PDF is required.
- **`APP_SECRET` provisioning.** Fernet/AES encryption of Stripe secrets is keyed off `APP_SECRET`, which is not in `<spec_deployments>` or the integration env keys. Confirm how it is injected and document that losing/rotating it requires re-entering credentials in `/admin/settings`.
- **Angular 19 vs. spec's Angular 22 features.** `provideZonelessChangeDetection` is experimental in v19 and `zone.js` is currently a dependency; the plan assumes zone-based change detection with signals. Also no `@angular/material` is installed — the plan builds plain CSS components instead.
- **PgBouncer / statement cache.** The spec's asyncpg `statement_cache_size: 0` mitigation does not apply to Prisma; if Colossus fronts Postgres with a transaction-mode pooler, `DATABASE_URL` needs `?pgbouncer=true&connection_limit=1`. Confirm the deployed topology.
- **Shipping address capture.** `Order.shippingAddressJson` is required, but the spec never says whether the address comes from the Stripe Checkout Session (`shipping_details`) or a form on `/checkout/:quoteId/shipping`. Plan assumes Stripe collects it and the webhook copies it across — confirm.
