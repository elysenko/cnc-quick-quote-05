What we read from your file

We flatten every LINE, ARC, CIRCLE, LWPOLYLINE and POLYLINE to measure the true cut path, then take the bounding box for nesting.

Unsupported content

Splines, text, dimensions and 3D geometry are reported and skipped rather than silently priced. If a file contains no supported entities at all we reject it instead of quoting zero.
